# BookMyForex Internal Knowledge Base

**Snapshot date:** 18 September 2026  
**Purpose:** Internal support/RAG reference built from publicly accessible BookMyForex pages.

## Usage rules
- Treat `current-offers.md`, exchange rates, fees, taxes, limits and turnaround times as time-sensitive.
- For customer-facing answers involving money, eligibility, compliance, TCS, fees or active promotions, verify against the linked source before committing.
- Location/currency SEO pages were intentionally consolidated instead of copied page-by-page.
- SWIFT-code directory pages and repetitive city-rate pages are excluded because they add little durable product knowledge.
- Where BookMyForex pages conflict, the conflict is explicitly flagged rather than silently choosing one value.
